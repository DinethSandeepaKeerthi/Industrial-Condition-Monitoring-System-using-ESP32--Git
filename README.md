🚀 Excited to share my latest IoT project!

I recently developed an Industrial Condition Monitoring System using ESP32 that can detect equipment failures before they happen.

🔍 The Problem:
Industrial machinery often fails unexpectedly, causing costly downtime and potential safety hazards.

💡 The Solution:
My system continuously monitors:
✅ Equipment temperature (NTC thermistor)
✅ Vibration levels (MPU6050 accelerometer)
✅ Sends instant SMS alerts via GSM (SIM800L)

⚡ How it works:
The system analyzes sensor data in real-time and categorizes equipment status as Normal, Warning, or Fault. When thresholds are exceeded, automated SMS notifications are sent to maintenance teams.

🛠️ Tech Stack:
ESP32 | C++ | I2C Communication | GSM/GPRS | Embedded Systems

This project demonstrates how affordable IoT solutions can transform industrial maintenance from reactive to proactive.
